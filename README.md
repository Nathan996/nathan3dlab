# Nathan 3D Lab — Link-in-bio

Mini site statique prêt pour GitHub Pages, Netlify, Vercel ou Cloudflare Pages.

## 1. À modifier avant mise en ligne

Ouvre `index.html` avec un éditeur texte et remplace :

- `YOUR_LINKEDIN_URL`
- `YOUR_EMAIL`

Le lien ArtStation est déjà configuré vers :
`https://www.artstation.com/b_nathan`

Tu peux aussi changer :
- `Open to opportunities`
- le texte de présentation
- les intitulés de boutons

## 2. Hébergement gratuit — GitHub Pages

1. Crée un compte GitHub si besoin.
2. Crée un nouveau repository, par exemple `nathan3dlab`.
3. Ajoute `index.html`, `styles.css` et le dossier `assets`.
4. Dans le repository : **Settings → Pages**.
5. Dans **Build and deployment**, sélectionne **Deploy from a branch**.
6. Branche : `main`, dossier : `/root`.
7. Sauvegarde.

GitHub te donnera ensuite une URL publique gratuite.

## 3. Hébergement gratuit — Netlify

Tu peux aussi glisser-déposer ce dossier complet dans Netlify Drop.
Le site sera mis en ligne automatiquement avec une URL gratuite.

## Structure

- `index.html`
- `styles.css`
- `assets/profile.png`

Aucun framework, aucune dépendance, aucun abonnement requis.
